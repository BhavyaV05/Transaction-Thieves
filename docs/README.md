# docs/ index

Start with the [project README](../README.md). This page lists every file under `docs/` by topic, one line each.
Most notes are working records written by the owner of a track (T1 Abhishek, T2 Bhavya, T3 Akshat, T4 Shreyas)
during the build; code docstrings cite them by path, so their names do not change. Files marked "generated" are
written by a script; do not edit them by hand.

## Start here

- [`RESULTS.md`](RESULTS.md): every test and validation result, with links.
- [`EXPERIMENTS.md`](EXPERIMENTS.md): experiments E1–E18, whether each ran on test, and the note for each.
- [`report/final/report.pdf`](report/final/report.pdf): the final report (LaTeX source in [`report/final/`](report/final/)).
- [`presentation/slides.pdf`](presentation/slides.pdf): the slides.
- [`t4_reduced_final.md`](t4_reduced_final.md): what the final run left out, and every deviation from the pre-registration.

# docs/ index

Reviewer map of everything under `docs/`. One line per file. "Superseded" means a later doc replaces it; the file is kept because scripts, tests or other docs still point to it. Generated files are written by scripts and must not be moved or renamed.

## Project-wide
- `schedule_nov10.md` - plan to the 10 Nov deadline (replaces the week-by-week tables in `tracks.md`).
- `hardware.md` - machines and setup (companion to `tracks.md` and `plan.md`).
- `external_code_check.md` - licence and code availability check for the external (Group C/D) baselines (T4, week 0).
- `baseline_fidelity.md` - per baseline: what is the authors' method, what we invented, what evidence shows fidelity.
- `rewrite_prereg_proposal.md` - prereg changes implied by the LangGraph rewrite (proposal; prereg/ untouched).
- `demo.md` - end-to-end demo of one alert (code in `ftm/demo/`).
- `ta_addendum.md` - draft reply to the TA about the review of `proposal_v5.pdf`.
- `proposal_v5.pdf` - the proposal submitted for review.
- `mid_submission/report.pdf` - mid-term submission report.
- `bench/t3-5070ti_qwen3-8b.json` - raw conversion benchmark on the 5070 Ti (T3 week 0).

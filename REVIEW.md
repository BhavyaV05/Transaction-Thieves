## What this is

Team **Cache me if you can** (LMA Group Project 2026). Federated anti-money-laundering investigation: a bank asks other banks small, typed, differentially-private questions, back-tests each question before it may affect a decision, and the final call is made by a formula, never by LLM text. Intro in [README.md](README.md); full plan in [plan.md](plan.md).

## How the final run works

[scripts/run_final.py](scripts/run_final.py) is the only place that may set `FTM_FINAL_RUN=1`. Its docstring has the commands.

1. `--plan` lists jobs, hours and machines; sets nothing.
2. `--dry-run` runs everything on the synthetic world with a mock LLM.
3. The real run needs `--run-id`, `--confirm-final <combined hash>` and `--machine s1|s3|cpu`; it is resumable. The preflight requires a matching `prereg/FREEZE.json`, a clean tree, the freeze commit in history and the E18 decision.
4. `--manifest-only` gathers job directories into `MANIFEST.json` (`MANIFEST.partial.json` while arms are missing). The analysis reads only the manifest.

Jobs are defined in `configs/final/`; the runbook is [docs/t4_final_run.md](docs/t4_final_run.md).

## Known deviations

All are recorded in [docs/t4_reduced_final.md](docs/t4_reduced_final.md); read it before interpreting any final table.

- **Reduced final run.** The full plan was estimated at about 188 GPU hours; a subset runs, with one G4 external agent (`bed_llm`) instead of two to three. Arms not run are reported as "not run".
- **FraudGT scored early.** Its test scoring ran once before the freeze, outside `run_final.py`, and is not re-run. See [docs/t1_final_run.md](docs/t1_final_run.md). It is HI-Small only, a baseline row and not an upper limit.
- **RAG and E15 ran on ada with a smaller alert world.** Both used the HI-Medium val alerts on the ada cluster, whose data copy lacks two bank views (`bank=70`, `bank=112`): 453 askable alerts against 460 on the main machine. The FinFRE pool groups were re-run on a separate 460-alert copy. Compare these arms only with each other, not with the main val runs. See [docs/t3_ada.md](docs/t3_ada.md) and [docs/t3_rag_bench.md](docs/t3_rag_bench.md).
- No TA for the pre-registration hash; equivalence margin fixed at 0.01 Brier; time-respecting upper limit only (issue #127); p0 v2 tolerance set after eval numbers existed. Details in the same note.
